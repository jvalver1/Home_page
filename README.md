# 🤖 Montykona INC — AI Projects & Demos Portfolio

> A personal portfolio of interactive web applications and browser games, **generated entirely by Artificial Intelligence** using various frontier and open-source language models. This repository serves as a living laboratory for exploring and comparing the code generation capabilities of modern LLMs.

---

## 🌐 Live Portal

The root `index.html` is a **dark-theme portfolio hub** that aggregates all sub-projects into a single, navigable dashboard. It features:

- **Glassmorphism UI** — frosted-glass cards with subtle backdrop blur and neon border highlights
- **Live iframe previews** — each project card renders a miniature, interactive preview of the actual running app
- **Collapsible category sections** — projects are grouped by type with smooth animated expand/collapse
- **Responsive grid layout** — adapts from 1 to 3 columns depending on screen width
- **Real-time clock** — live date/time display in the header

## 🛠️ Tech Stack

All projects are **pure frontend** — no backend, no build step required for most. Just open in a browser.

| Technology | Usage |
|---|---|
| **HTML5** | Structure for all demos and games |

## 🎮 Project Highlights

### 🐍 Snake — The AI Benchmark
The Snake game is the most extensively benchmarked project in this portfolio. **13 different AI models** each produced their own implementation, making it an ideal apples-to-apples comparison of:
- Code quality and correctness out-of-the-box
- Visual creativity (neon, garden, graffiti, realistic themes)
- Game logic robustness (collision detection, scoring, speed scaling)

### 🟦 Tetris — Classic Reinterpreted
Three Tetris implementations, each from a different model, allowing direct comparison of how different AI systems approach a well-known algorithmic problem involving:
- Piece rotation matrices
- Line-clear detection
- Game-loop timing

### 🕐 Digital Clock (Electron App)
The only non-browser project — a desktop application built with **Electron**, packaging a web-based clock into a native `.exe`. Demonstrates cross-platform desktop delivery from a web stack.

### 🌊 Tridimensional Sine Wave
A real-time 3D sine wave renderer using the Canvas API, demonstrating AI capability in mathematical visualisation and animation loops.

## 🚀 Running Locally

No installation needed for most projects. Simply:

```bash
git clone https://github.com/jvalver1/Home_page.git
cd Home_page
# Open index.html in your browser
start index.html   # Windows
open index.html    # macOS
```

For the **DigitalClock** Electron app:

```bash
cd DigitalClock
npm install
npm start
```
